# campaign/：比赛工作区的文本证据

比赛期间，代码和文档在 git 里（本仓库的 `docs/`、各分支），运行产生的证据放在一个不进 git 的工作区。这里收录的是那个工作区里的文本证据，按原目录结构保留，路径和 `docs/` 里的引用一致。

## 收录规则

- **只收文本**：账本（.jsonl）、运行结果和读数（.json）、报告与笔记（.md/.txt/.csv）、我们写的实验驱动脚本和测试。单文件不超过 1 MB；日志不超过 256 KB。
- **不收**：主办方原件（参赛须知、赛题需求及其副本、平台任务清单、运行器脚本、官方基准仓库克隆）；运行 bundle 里的生成应用和包源码副本（包源码在 git 历史里）；截图、zip 等二进制；LLM 调用 trace（提示词里嵌着完整赛题需求）。逐字节相同的副本只留一份。
- **官方运行日志**去掉了 `[oneshot] trace` 行（同样是因为嵌着需求原文），保留修复轮次、费用和失败清单。
- 本机路径统一写成 `~`，个人标识和凭据已脱敏。
